# 팀 가입 신청 취소

## 기능 목적

- 회원이 본인이 보낸 팀 가입 신청을 취소할 수 있다.

## 비즈니스 규칙

- 로그인한 회원만 요청할 수 있다.
- 존재하는 팀의 가입 신청만 취소할 수 있다.
- 로그인한 회원이 현재 DB에 존재해야 한다.
- 본인의 가입 신청만 취소할 수 있다.
- 존재하는 가입 신청만 취소할 수 있다.
- URL의 팀과 가입 신청이 속한 팀이 같아야 한다.
- 취소된 가입 신청은 삭제한다.
- 가입 신청을 취소해도 TeamMember에는 변화가 없다.

## 처리 순서

1. JWT에서 로그인 회원 ID를 가져온다.
2. teamId에 해당하는 Team이 존재하는지 확인한다.
3. 로그인 회원이 존재하는지 확인한다.
4. 로그인 회원의 가입 신청을 조회한다.
5. 가입 신청이 URL의 팀에 보낸 신청인지 확인한다.
6. 가입 신청을 삭제한다.

## API

DELETE /api/teams/{teamId}/join-requests/me

## 응답

204 No Content

## 테스트 항목

- 본인 가입 신청 취소 성공
- 취소 후 가입 신청 삭제
- 취소 후 TeamMember 변화 없음
- 존재하지 않는 팀 취소 실패
- 존재하지 않는 회원 취소 실패
- 가입 신청이 없는 회원 취소 실패
- 다른 팀에 보낸 가입 신청 취소 실패
- 다른 회원의 가입 신청을 취소할 수 없음
