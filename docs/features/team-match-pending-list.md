# PENDING 매치 목록 조회

## 기능 목적

- 사용자가 현재 상대 팀을 모집 중인 매치 목록을 조회할 수 있다.

## 비즈니스 규칙

- TeamMatchStatus.PENDING인 매치만 조회한다.
- 팀장 여부와 관계없이 조회할 수 있다.
- 팀 소속 여부와 관계없이 조회할 수 있다.
- 경기 예정 시간이 빠른 순서로 정렬한다.
- 경기 예정 시간이 같다면 먼저 등록된 순서로 정렬한다.
- 홈팀 정보만 반환한다.
- 원정팀 관련 정보는 반환하지 않는다.
- 조회 결과가 없으면 빈 배열을 반환한다.
- 한 팀은 PENDING 매치를 하나만 가질 수 있지만 여러 팀의 PENDING 매치는 함께 조회될 수 있다.

## 처리 순서

1. status가 PENDING인 TeamMatch를 조회한다.
2. homeTeam을 Fetch Join으로 함께 조회한다.
3. playedAt 오름차순으로 정렬한다.
4. TeamMatchPendingResponse로 변환한다.
5. 목록을 반환한다.

## API

GET /api/matches/pending

## 응답

200 OK

## 테스트 항목

- PENDING 매치 목록 조회 성공
- 여러 팀의 PENDING 매치 조회
- 경기 예정 시간이 빠른 순서로 정렬
- 홈팀 정보 반환
- 원정팀 정보 미포함
- 조회 결과가 없으면 빈 배열 반환
- 홈팀 조회 과정에서 N+1이 발생하지 않음
