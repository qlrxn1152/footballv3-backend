# 팀원 강퇴

## 기능 목적

- 현재 팀장이 같은 팀의 일반 팀원을 강퇴할 수 있다.

## 비즈니스 규칙

- 로그인한 회원만 요청할 수 있다.
- 존재하는 팀에서만 강퇴할 수 있다.
- 로그인한 회원이 현재 DB에 존재해야 한다.
- 해당 팀의 현재 팀장만 강퇴할 수 있다.
- 강퇴 대상 회원이 현재 DB에 존재해야 한다.
- 강퇴 대상의 TeamMember가 존재해야 한다.
- 강퇴 대상은 URL의 팀에 소속돼 있어야 한다.
- TeamRole.MEMBER인 회원만 강퇴할 수 있다.
- 팀장은 강퇴할 수 없다.
- 자기 자신을 강퇴할 수 없다.
- 강퇴하면 대상 회원의 TeamMember만 삭제한다.
- 대상 Member 계정은 삭제하지 않는다.
- 다른 팀원과 다른 팀 데이터에는 영향을 주지 않는다.

## 처리 순서

1. JWT에서 로그인 회원 ID를 가져온다.
2. Team과 leaderMember를 조회한다.
3. 로그인 회원이 존재하는지 확인한다.
4. 로그인 회원이 현재 팀장인지 확인한다.
5. 강퇴 대상 Member를 조회한다.
6. 강퇴 대상 TeamMember를 조회한다.
7. 대상 TeamMember가 해당 팀 소속인지 확인한다.
8. 대상 TeamMember의 역할이 MEMBER인지 확인한다.
9. 대상 TeamMember를 삭제한다.

## API

DELETE /api/teams/{teamId}/members/{targetMemberId}

## 응답

204 No Content

## 테스트 항목

- 일반 팀원 강퇴 성공
- 강퇴 후 대상 TeamMember 삭제
- 강퇴 후 Member 계정 유지
- 강퇴 후 다른 팀원 유지
- 팀장이 아닌 회원의 강퇴 실패
- 팀장 자기 자신 강퇴 실패
- 존재하지 않는 팀 실패
- 존재하지 않는 로그인 회원 실패
- 존재하지 않는 대상 회원 실패
- 팀에 소속되지 않은 대상 실패
- 다른 팀 소속 회원 강퇴 실패
- 강퇴 후 다른 팀 가입 신청 가능
