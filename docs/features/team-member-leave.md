# 일반 팀원 팀 탈퇴

## 기능 목적

- 일반 팀원이 본인이 소속된 팀에서 탈퇴할 수 있다.

## 비즈니스 규칙

- 로그인한 회원만 요청할 수 있다.
- 존재하는 팀에서만 탈퇴할 수 있다.
- 로그인한 회원이 현재 DB에 존재해야 한다.
- 로그인한 회원의 TeamMember가 존재해야 한다.
- 로그인한 회원이 URL의 팀에 소속돼 있어야 한다.
- TeamRole.MEMBER만 탈퇴할 수 있다.
- TeamRole.LEADER는 일반 탈퇴를 할 수 없다.
- 탈퇴하면 해당 회원의 TeamMember를 삭제한다.
- 다른 팀원의 TeamMember에는 영향을 주지 않는다.
- Team 자체는 삭제하지 않는다.

## 처리 순서

1. JWT에서 로그인 회원 ID를 가져온다.
2. teamId에 해당하는 Team이 존재하는지 확인한다.
3. 로그인 회원이 존재하는지 확인한다.
4. 로그인 회원의 TeamMember를 조회한다.
5. TeamMember의 팀과 URL의 팀이 같은지 확인한다.
6. 로그인 회원이 팀장이 아닌지 확인한다.
7. TeamMember를 삭제한다.

## API

DELETE /api/teams/{teamId}/members/me

## 응답

204 No Content

## 테스트 항목

- 일반 팀원 탈퇴 성공
- 탈퇴 후 TeamMember 삭제
- 탈퇴 후 팀의 인원 수 감소
- 팀장 탈퇴 실패
- 다른 팀 주소를 통한 탈퇴 실패
- 팀에 소속되지 않은 회원 탈퇴 실패
- 존재하지 않는 팀 탈퇴 실패
- 존재하지 않는 회원 탈퇴 실패
- 탈퇴 후 다른 팀 가입 신청 가능
