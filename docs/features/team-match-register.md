# 매치 모집 등록

## 기능 목적

- 팀장이 자신의 팀을 홈팀으로 설정해 매치 상대를 모집할 수 있다.

## 비즈니스 규칙

- 로그인한 회원만 요청할 수 있다.
- 존재하는 팀만 매치를 등록할 수 있다.
- 로그인한 회원이 현재 DB에 존재해야 한다.
- 해당 팀의 현재 팀장만 매치를 등록할 수 있다.
- 경기 예정 일시는 현재 시간보다 미래여야 한다.
- 동일한 팀이 동일한 경기 예정 시간으로 중복 등록할 수 없다.
- 등록된 매치의 홈팀은 요청한 팀으로 설정한다.
- 등록 시 원정팀은 존재하지 않는다.
- 등록 시 상태는 PENDING이다.
- 등록 시 원정팀 ( awayTeam ) 은 null 로 설정된다.
- 매치 등록 시각을 저장한다.
- PENDING 매치가 이미 존재한다면, 추가로 등록할 수 없다.

## 상태

- PENDING: 상대 팀 모집 중
- MATCHED: 상대 팀 확정
- COMPLETED: 경기 종료 및 결과 입력 완료

## 처리 순서

1. JWT에서 로그인 회원 ID를 가져온다.
2. Team과 leaderMember를 조회한다.
3. 로그인 회원이 존재하는지 확인한다.
4. 로그인 회원이 해당 팀의 팀장인지 확인한다.
5. 경기 예정 일시가 미래인지 확인한다.
6. 같은 팀과 같은 시간의 중복 등록인지 확인한다.
7. PENDING 상태의 매치를 저장한다.

## API

POST /api/teams/{teamId}/matches

## 테스트 항목

- 매치 모집 등록 성공
- 등록 상태가 PENDING인지 확인
- 원정팀이 null인지 확인
- DB 저장 확인
- 팀장이 아닌 회원의 등록 실패
- 존재하지 않는 팀 실패
- 존재하지 않는 로그인 회원 실패
- 과거 경기 시간 실패
- 현재 시간 경기 실패
- 동일한 시간 중복 등록 실패
- 서로 다른 시간에는 여러 모집 글 등록 가능
- 팀장 위임 후 권한 반영
