# PENDING 매치 수락

## 기능 목적

- 다른 팀의 팀장이 PENDING 매치를 수락할 수 있다.
- 매치를 수락하면 수락한 팀이 원정팀으로 지정된다.
- 매치 상태는 PENDING에서 MATCHED로 변경된다.

## 비즈니스 규칙

- 로그인한 회원만 요청할 수 있다.
- 존재하는 원정팀만 요청할 수 있다.
- 로그인한 회원이 현재 DB에 존재해야 한다.
- 로그인한 회원은 원정팀의 현재 팀장이어야 한다.
- 존재하는 매치만 수락할 수 있다.
- PENDING 상태의 매치만 수락할 수 있다.
- 홈팀은 자신의 매치를 직접 수락할 수 없다.
- 경기 예정 시간이 지난 매치는 수락할 수 없다.
- 수락 성공 시 awayTeam을 설정한다.
- 수락 성공 시 상태를 MATCHED로 변경한다.
- 수락 성공 시 matchedAt을 저장한다.
- 동시에 여러 팀이 수락하더라도 한 팀만 성공해야 한다.

## 처리 순서

1. 원정팀과 leaderMember를 조회한다.
2. 로그인 회원을 조회한다.
3. 로그인 회원이 원정팀의 팀장인지 확인한다.
4. 매치를 비관적 쓰기 잠금으로 조회한다.
5. 매치가 PENDING 상태인지 확인한다.
6. 원정팀과 홈팀이 다른 팀인지 확인한다.
7. 경기 예정 시간이 미래인지 확인한다.
8. awayTeam을 설정한다.
9. 상태를 MATCHED로 변경한다.
10. matchedAt을 저장한다.

## API

POST /api/teams/{awayTeamId}/matches/{matchId}/accept
