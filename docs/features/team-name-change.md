# 팀 이름 변경

## 기능 목적

- 현재 팀장이 자신이 운영하는 팀의 이름을 변경할 수 있다.

## 비즈니스 규칙

- 로그인한 회원만 요청할 수 있다.
- 존재하는 팀만 이름을 변경할 수 있다.
- 로그인한 회원이 현재 DB에 존재해야 한다.
- 해당 팀의 현재 팀장만 이름을 변경할 수 있다.
- 팀 이름의 앞뒤 공백은 제거한다.
- 팀 이름은 2자 이상 10자 이하이어야 한다.
- 현재 팀 이름과 같은 이름으로는 변경할 수 없다.
- 다른 팀이 이미 사용 중인 이름으로는 변경할 수 없다.
- 검증에 통과하면 Team.teamName을 변경한다.

## 처리 순서

1. JWT에서 로그인 회원 ID를 가져온다.
2. Team과 leaderMember를 조회한다.
3. 로그인 회원의 존재 여부를 확인한다.
4. 로그인 회원이 현재 팀장인지 확인한다.
5. 새 팀 이름의 앞뒤 공백을 제거한다.
6. 팀 이름 길이를 확인한다.
7. 기존 팀 이름과 같은지 확인한다.
8. 다른 팀이 사용하는 이름인지 확인한다.
9. Team의 이름을 변경한다.

## API

PATCH /api/teams/{teamId}/name

## 테스트 항목

- 팀 이름 변경 성공
- 변경된 이름 DB 반영 확인
- 앞뒤 공백 제거 확인
- 팀장이 아닌 회원의 변경 실패
- 현재 이름과 같은 이름으로 변경 실패
- 공백 제거 후 현재 이름과 같은 경우 실패
- 이미 존재하는 다른 팀 이름으로 변경 실패
- 2자 미만 이름 실패
- 10자 초과 이름 실패
- 존재하지 않는 팀 실패
- 존재하지 않는 로그인 회원 실패
- 팀장 위임 후 권한 반영 확인
