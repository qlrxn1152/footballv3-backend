# 팀 해체

## 기능 목적

- 현재 팀장이 자신이 운영하는 팀을 해체할 수 있다.

## 비즈니스 규칙

- 로그인한 회원만 요청할 수 있다.
- 존재하는 팀만 해체할 수 있다.
- 로그인한 회원이 현재 DB에 존재해야 한다.
- 해당 팀의 현재 팀장만 팀을 해체할 수 있다.
- 팀에 남아 있는 가입 신청을 모두 삭제한다.
- 팀에 소속된 TeamMember를 모두 삭제한다.
- 마지막에 Team을 삭제한다.
- 팀에 소속됐던 Member 계정은 삭제하지 않는다.
- 다른 팀의 데이터에는 영향을 주지 않는다.
- 모든 삭제 작업은 하나의 트랜잭션에서 처리한다.

## 처리 순서

1. JWT에서 로그인 회원 ID를 가져온다.
2. Team과 leaderMember를 조회한다.
3. 로그인 회원의 존재 여부를 확인한다.
4. 로그인 회원이 현재 팀장인지 확인한다.
5. 해당 팀의 TeamJoinRequest를 모두 삭제한다.
6. 해당 팀의 TeamMember를 모두 삭제한다.
7. Team을 삭제한다.

## API

DELETE /api/teams/{teamId}

## 응답

204 No Content

## 테스트 항목

- 팀장 팀 해체 성공
- 해체 후 Team 삭제 확인
- 해체 후 TeamMember 전체 삭제 확인
- 해체 후 TeamJoinRequest 전체 삭제 확인
- 해체 후 Member 계정 유지 확인
- 다른 팀 데이터 유지 확인
- 팀장이 아닌 회원의 해체 실패
- 존재하지 않는 팀의 해체 실패
- 존재하지 않는 로그인 회원의 해체 실패
- 팀장 위임 이후 기존 팀장의 해체 실패
- 팀장 위임 이후 새로운 팀장의 해체 성공
- 해체 후 기존 팀원이 다른 팀에 가입할 수 있음
