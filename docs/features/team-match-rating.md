# 경기 결과 팀 레이팅 반영

## 기능 목적

- 경기 결과가 등록되면 홈팀과 원정팀의 레이팅을 변경한다.

## 레이팅 정책

- 모든 팀의 최초 레이팅은 1500이다.
- 홈팀 승리 시 홈팀 +30, 원정팀 -30
- 원정팀 승리 시 원정팀 +30, 홈팀 -30
- 무승부 시 양 팀 +10
- 결과 등록에 실패한 경우 레이팅은 변경되지 않는다.
- 동일한 경기 결과로 레이팅이 두 번 반영되어서는 안 된다.

## 처리 순서

1. 기존 경기 결과 등록 검증을 수행한다.
2. TeamMatchResult를 생성한다.
3. TeamMatch를 COMPLETED로 변경한다.
4. 홈팀과 원정팀에 경기 결과에 따른 레이팅을 반영한다.
5. 트랜잭션 종료 시 변경된 팀 레이팅을 DB에 반영한다.

## 이번 기능에서 제외

- 동시성 처리
- 실제 ELO 공식
- 레이팅 변경 이력
