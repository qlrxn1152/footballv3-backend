# MATCHED 매치 목록 조회

## 기능 목적

- 사용자가 현재 성사된 매치 목록을 조회할 수 있다.
- 홈팀과 원정팀 정보를 함께 확인할 수 있다.

## 비즈니스 규칙

- TeamMatchStatus.MATCHED 상태인 매치만 조회한다.
- 홈팀과 원정팀 정보를 모두 반환한다.
- 경기 예정 시간이 빠른 순서로 반환한다.
- 경기 예정 시간이 같으면 matchId가 작은 순서로 반환한다.
- 팀장 여부와 관계없이 조회할 수 있다.
- 팀 소속 여부와 관계없이 조회할 수 있다.
- 조회 결과가 없으면 빈 배열을 반환한다.
- 경기 예정 시간이 지났더라도 상태가 MATCHED이면 조회한다.
- 동시성 처리는 이번 기능 범위에 포함하지 않는다.

## 처리 순서

1. MATCHED 상태의 TeamMatch를 조회한다.
2. homeTeam과 awayTeam을 Fetch Join한다.
3. playedAt 오름차순으로 정렬한다.
4. TeamMatchMatchedResponse로 변환한다.
5. 목록을 반환한다.

## API

GET /api/matches/matched

## 응답

200 OK

## 테스트 항목

- MATCHED 매치 목록 조회 성공
- 홈팀과 원정팀 정보 반환
- PENDING 매치 제외
- 경기 예정 시간 오름차순 정렬
- 같은 경기 시간에서는 matchId 순서로 정렬
- 데이터가 없으면 빈 배열 반환
- 홈팀과 원정팀 조회 과정에서 N+1이 발생하지 않음
