# 팀 레이팅 랭킹 조회

## 기능 목적

- 현재 팀 레이팅을 기준으로 전체 팀의 순위를 조회한다.

## API

GET /api/teams/rankings

## 비즈니스 규칙

- 모든 팀을 조회한다.
- 레이팅이 높은 팀부터 반환한다.
- 같은 레이팅을 가진 팀은 같은 순위를 가진다.
- 같은 레이팅인 팀은 teamId가 작은 순서로 표시한다.
- 동점 다음 순위는 앞에 존재하는 팀 수만큼 건너뛴다.
- 팀이 존재하지 않으면 빈 배열을 반환한다.
- 로그인하지 않아도 조회할 수 있다.

## 순위 예시

- 1560점: 1위
- 1530점: 2위
- 1530점: 2위
- 1500점: 4위

## 정렬

- rating DESC
- teamId ASC

## 이번 기능에서 제외

- 페이징
- 기간별 랭킹
- 시즌 랭킹
- 레이팅 이력
- 실제 ELO 계산
- 동시성 처리
