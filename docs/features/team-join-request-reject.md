# 팀 가입 신청 거절

## 기능 목적

- 팀장이 자신의 팀에 들어온 가입 신청을 거절할 수 있다.

## 비즈니스 규칙

- 로그인한 회원만 요청할 수 있다.
- 존재하는 팀만 요청할 수 있다.
- 해당 팀의 팀장만 가입 신청을 거절할 수 있다.
- 존재하는 가입 신청만 거절할 수 있다.
- 해당 팀에 들어온 가입 신청만 거절할 수 있다.
- 거절된 가입 신청은 삭제한다.
- 가입 신청을 거절해도 TeamMember는 생성하지 않는다.

## 처리 순서

1. JWT에서 로그인 회원 ID를 가져온다.
2. Team과 leaderMember를 조회한다.
3. 로그인 회원의 존재 여부를 확인한다.
4. 로그인 회원이 해당 팀의 팀장인지 확인한다.
5. 가입 신청을 조회한다.
6. 해당 팀의 가입 신청인지 확인한다.
7. 가입 신청을 삭제한다.

## API

POST /api/teams/{teamId}/join-requests/{requestId}/reject

## 응답

204 No Content

## 테스트 항목

- 가입 신청 거절 성공
- 거절 후 가입 신청 삭제 확인
- 거절 후 TeamMember가 생성되지 않는지 확인
- 팀장이 아닌 회원의 거절 실패
- 존재하지 않는 팀의 거절 실패
- 존재하지 않는 가입 신청의 거절 실패
- 다른 팀에 들어온 가입 신청의 거절 실패
