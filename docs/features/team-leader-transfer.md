# 팀장 위임

## 기능 목적

- 현재 팀장이 같은 팀의 일반 팀원에게 팀장 권한을 위임할 수 있다.

## 비즈니스 규칙

- 로그인한 회원만 요청할 수 있다.
- 존재하는 팀에서만 팀장을 변경할 수 있다.
- 현재 팀장만 팀장 권한을 위임할 수 있다.
- 위임받을 회원이 실제로 존재해야 한다.
- 위임받을 회원은 해당 팀에 소속돼 있어야 한다.
- 위임받을 회원의 역할은 MEMBER여야 한다.
- 현재 팀장 자신에게는 위임할 수 없다.
- 기존 팀장의 역할은 MEMBER로 변경한다.
- 새로운 팀장의 역할은 LEADER로 변경한다.
- Team의 leaderMember를 새로운 팀장으로 변경한다.
- 세 가지 변경은 하나의 트랜잭션에서 처리한다.

## 처리 순서

1. JWT에서 로그인 회원 ID를 가져온다.
2. Team과 현재 leaderMember를 조회한다.
3. 로그인 회원이 존재하는지 확인한다.
4. 로그인 회원이 현재 팀장인지 확인한다.
5. 새로운 팀장 회원이 존재하는지 확인한다.
6. 현재 팀장과 새로운 팀장이 같은 회원인지 확인한다.
7. 기존 팀장의 TeamMember를 조회한다.
8. 새로운 팀장의 TeamMember를 조회한다.
9. 두 TeamMember가 해당 팀 소속인지 확인한다.
10. 새로운 팀장의 역할이 MEMBER인지 확인한다.
11. Team의 leaderMember를 변경한다.
12. 기존 팀장의 역할을 MEMBER로 변경한다.
13. 새로운 팀장의 역할을 LEADER로 변경한다.

## API

PATCH /api/teams/{teamId}/leader

## 테스트 항목

- 팀장 위임 성공
- Team의 leaderMember 변경 확인
- 기존 팀장의 역할이 MEMBER로 변경
- 새 팀장의 역할이 LEADER로 변경
- 팀장이 아닌 회원의 위임 실패
- 자기 자신에게 위임 실패
- 존재하지 않는 팀 실패
- 존재하지 않는 대상 회원 실패
- 팀에 소속되지 않은 회원에게 위임 실패
- 다른 팀 소속 회원에게 위임 실패
- 위임 후 새로운 팀장만 팀장 기능 사용 가능
