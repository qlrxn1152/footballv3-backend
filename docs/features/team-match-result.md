# 경기 결과 입력

## 기능 목적

- 홈팀 팀장이 MATCHED 매치의 경기 결과를 입력한다.
- 결과 입력이 완료되면 매치 상태를 COMPLETED로 변경한다.

## 비즈니스 규칙

- 로그인한 회원만 요청할 수 있다.
- 존재하는 매치만 결과를 입력할 수 있다.
- 로그인한 회원이 현재 DB에 존재해야 한다.
- 홈팀의 현재 팀장만 결과를 입력할 수 있다.
- MATCHED 상태의 매치만 결과를 입력할 수 있다.
- 홈팀과 원정팀 점수는 0 이상이어야 한다.
- 한 매치에는 결과를 한 번만 입력할 수 있다.
- 홈팀 점수가 높으면 홈팀이 승리팀이다.
- 원정팀 점수가 높으면 원정팀이 승리팀이다.
- 점수가 같으면 무승부이며 승리팀은 null이다.
- 결과 입력 후 매치 상태는 COMPLETED가 된다.
- 결과 입력 완료 시간을 저장한다.
- 팀 레이팅 반영은 별도 기능으로 처리한다.
- 동시성 처리는 별도 기능으로 처리한다.

## 처리 순서

1. 로그인 회원을 조회한다.
2. TeamMatch와 홈팀·원정팀을 조회한다.
3. 로그인 회원이 홈팀의 현재 팀장인지 확인한다.
4. 기존 결과가 존재하는지 확인한다.
5. 매치 상태가 MATCHED인지 확인한다.
6. 점수를 검증한다.
7. TeamMatchResult를 저장한다.
8. TeamMatch를 COMPLETED로 변경한다.
9. 결과를 반환한다.

## API

POST /api/matches/{matchId}/result
